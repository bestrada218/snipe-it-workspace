# Etiquetas

Cómo imprimir las etiquetas de los equipos y qué datos llevan.

## Qué lleva cada etiqueta

La etiqueta está pensada para que la **placa** se lea de un vistazo:

1. **Placa**, primero y en negrita.
2. **Modelo** del equipo.
3. **Compañía** (si el activo no tiene compañía, se usa el nombre del sitio).
4. **Serie**, al final.

Al lado va el **código de barras o QR** de la placa, sin tapar el texto.

## Imprimir

- **Varias a la vez**: en la lista de activos marca los que quieras y elige **Generar etiquetas** en las acciones de grupo.
- **Una sola**: en la página del activo, botón de etiqueta (el ícono de código de barras) en la barra de acciones.

Se abre una vista lista para imprimir con el formato de etiqueta configurado. Usa la impresora de etiquetas y revisa en la vista previa que el tamaño coincida con el rollo.

## Configurar el formato

En **Configuraciones → Etiquetas** un administrador define:

- **Nuevo motor de etiquetas**: actívalo y guarda antes de cambiar lo demás. Permite elegir la plantilla según el tamaño de etiqueta que uses.
- **Plantilla**: el tamaño y la distribución.
- **Campos**: qué datos aparecen y en qué orden. La placa siempre se imprime primero; los demás campos (modelo, compañía, serie…) se ordenan en la lista.
- El **tipo de código** (QR o código de barras) y si se imprime el logo.

> Si cambias la plantilla, imprime primero una etiqueta de prueba.
