# Getting started

How the app is organized: the menu, the dashboard, search, language and where to see what changed in each version.

## The side menu

The menu groups everything in these blocks:

| Block | What is there |
| --- | --- |
| **Inventory** | Assets, fixed assets (when turned on), accessories, kits and the other inventory modules. |
| **Tracking** | What is moving or pending: equipment in transit, returns, replacement alerts, upcoming audits and check-ins, duplicate assignments, maintenances, requests and unaccepted items. |
| **People** | Users, departments and groups. |
| **Reports** | Activity and other reports. |
| **Administration** | Import and **Settings** (administrators only). |
| **Help** | This help center, the asset tag guide and requestable items. |

Numbers next to a menu entry count what is pending there, such as open returns or shipments to confirm. Amber means something is already late.

> The **Create New** button at the top creates anything (asset, accessory, person…) from any page.

## The dashboard and "Needs attention"

The dashboard opens with the **Needs attention** list: everything that needs an action, in one place, each with a button to deal with it. Items show up when:

- an asset passed its **mandatory replacement** date or is due within 15 days;
- a **shipment** arrives today or is late and its delivery has to be confirmed;
- a **return** has not moved for days;
- an asset should have been **checked in** and is still assigned;
- an asset's **audit** is overdue or it is past its **end of life**;
- a **maintenance** is past its completion date;
- a person is **leaving** soon and still holds equipment;
- a **license** is about to expire;
- there are pending **requests** or **acceptances**.

When there is nothing, it says "All clear".

## Search

The **Search tag, serial or person** box at the top of every page finds assets by tag, serial number or model, and people by name. Part of the text is enough, such as the last digits of a serial. Each person only sees results from the modules they are allowed to open.

## Lists and forms

- Above the asset list, **status chips** (All, Deployed, Ready to deploy…) filter with one click.
- Each row has one main action and a **⋯ More actions** menu with the rest.
- Bulk actions (check out, check in, edit, print labels) appear when one or more rows are selected.
- On long forms the **Save** button always stays in reach at the bottom.

## Language and data in English

The interface is in **English** or **Spanish**; each person chooses it in their profile. **What people type** (notes, reasons, damage descriptions, justifications) **is always written in English**, so the whole team can read it. That is why text fields show English examples.

## Version and changes

The installed version is shown at the bottom of every page, with its version number. Clicking it opens [Changes by version](route:changelog), with what each version brought.

- **Snipe-IT Workspace** has its own numbering: 0.1, 0.1.1 for small fixes, 0.2 for new features and 1.0 for the formal release.
- **Snipe-IT** is the original software it is based on; its version is shown separately.
