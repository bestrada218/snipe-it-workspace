# Security

Two-factor authentication, protected sections and who can do what.

## Two-factor authentication (2FA)

Two-factor asks, besides the password, for a **6-digit code** that changes every 30 seconds and is generated by an app on your phone: Google Authenticator, Microsoft Authenticator, 1Password or another.

### Turning it on for your account

The first time you are asked:

1. Install an authenticator app on your phone.
2. Scan the **QR code** shown on screen. If you cannot scan it, type the key shown below it.
3. Type the 6-digit code the app shows and confirm.

From then on, whenever it is asked, open the app and type the current code.

> If you change or lose your phone, ask an administrator to **reset your two-factor** from your user profile; next time you set it up again with the new phone.

### Requiring it at sign-in

In **Settings → Security**, **Enable two-factor authentication**, an administrator chooses:

- **Disabled**: not asked at sign-in.
- **Selective**: only for people who turn it on.
- **Required for all users**: everyone must use it.

Requiring it at least for administrators is recommended.

## Sections that always ask for confirmation

The [Cloud copies](help:backups#cloud-copies) and [Email](help:email-and-summary) sections hold keys and passwords of the system. So:

- Only **superadmins** can open it.
- **Every time it is opened**, it asks for the **password** and a **two-factor code**, even if you were there a minute ago. Reloading the page or coming back also asks.
- **Two-factor is mandatory** here: if your account does not have it, the same screen asks you to set it up before letting you in.
- The keys are stored **encrypted** and never shown again.

## Permissions

What each person can see and do depends on their **groups** and permissions:

- **Superadmins** can do everything, Settings included.
- **Groups** set permissions per module (view, create, edit, check out, delete).
- A group can be [limited to a location](help:locations-and-inventory#groups-limited-to-a-location).
- Search and lists only show what each person is allowed to see.
